1. 31-Bit Bitmask Nonogram Line Deduction & Switching-Component Proofs

A Nonogram (Picross / Griddlers) puzzle specifies ordered contiguous block lengths $R = [r_0, r_1, \dots, r_{k-1}]$ along each row and column of an $H \times W$ binary grid. Naive backtracking over pixels explodes as $O(2^{HW})$, whereas encoding each row and column into a 31-bit integer mask turns run placement and forced-cell intersection into register-level bitwise operations.

Why 31 Bits Instead of 32 in JavaScript?

ECMAScript bitwise operators (<<, |, &, ^) coerce Numbers to signed 32-bit two's-complement integers (Int32), where 1 << 31 evaluates to -2147483648. Restricting single-word masks to $1 \le N \le 31$ with 0x7fffffff keeps all block masks non-negative across standard $5\times 5$ through $30\times 30$ puzzles.

minSpan[i] = r[i] + 1 + minSpan[i + 1],   blockMask(p, r) = ((1 << r) - 1) << p
forcedFilledMask = fullMask ^ unionEmpty,   forcedEmptyMask = fullMask ^ unionFill

Instead of enumerating exponentially many full-line combinations on sparse clues such as [1, 1, 1, 1, 1], deduceNonogramLine memoizes suffix states (runIdx, startPos) in flat typed arrays (Float64Array / Int32Array), bounding worst-case line complexity to $O(k \cdot N^2)$. When generating puzzles from photos, solveNonogramBitmask verifies both unique === true (eliminating $2 \times 2$ checkerboard switching components) and lineSolvable === true so players never have to guess.

2. 2D 4-Connected BFS Dropout Detection & Shortest-Euclidean Tab Synthesis

When converting a portrait photo or script lettering into a wood scroll-saw pattern or Mylar airbrush stencil, binary thresholding partitions the canvas into keep material (1 = solid wood / stencil sheet) and cut void (0 = saw kerf / open window). Any solid component that lacks an orthogonal path to the outer plaque border becomes a floating dropout island that falls into the dust collection chute the moment its surrounding contour is cut.

Strict 4-Connectivity vs. Diagonal Corner Snap

Raster contour libraries frequently group pixels using 8-neighbor Moore adjacency. In physical woodworking, two solid cells touching only diagonally at $(x, y)$ and $(x+1, y+1)$ meet at a zero-width mathematical point—a 0.034" scroll saw blade severs both kerfs right through the vertex. detectFloatingIslands enforces strict 4-connected Von Neumann flood fill seeded from the outer frame:

import { detectFloatingIslands, autoBridgeIslands } from "./src/index.mjs";

const audit = detectFloatingIslands(keepMask, width, height);
// audit.stateMask: 0 = cut void, 1 = frame-anchored wood, 2 = floating dropout island

if (audit.islandCount > 0) {
  // Iteratively bridges the globally closest (anchorBoundary <-> islandBoundary) Euclidean pair,
  // promoting newly welded rings so nested islands cascade across short local tabs!
  const welded = autoBridgeIslands(keepMask, width, height, 1);
  // welded.remainingIslandCount === 0
}

3. Scroll Saw 3-Tooth Engagement Physics & Wire-Gauge Pilot Drills

Scroll saw blade sizing balances two competing mechanical failure modes across stock thickness $t_{\text{in}}$:

  • Under-Engagement (< 3 Teeth in Stock): Tooth gullets straddle the entire board thickness, hooking bottom-face fibers on the upstroke and violently slamming the workpiece against the saw table.
  • Over-Engagement (> 10 Teeth in Stock): Sawdust generated near the top of the kerf fills every gullet before exiting the bottom face, creating friction heat that burns cherry, hard maple, and walnut black.
